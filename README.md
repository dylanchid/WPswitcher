# WPswitcher

WPswitcher is a macOS app for organizing and rotating wallpapers via playlists.

## Getting started

1. Open the project in Xcode: `WPswitcher.xcodeproj`.
2. Build and run the `WPswitcher` scheme.

## Project layout

- `WPswitcher/App` - app entry point and AppDelegate.
- `WPswitcher/Models` - data models and domain types.
- `WPswitcher/Persistence` - Core Data stack + managed objects.
- `WPswitcher/Services` - service layer and registries.
- `WPswitcher/ViewModels` - view models for SwiftUI views.
- `WPswitcher/Views` - SwiftUI views and UI helpers.
- `WPswitcher/Assets.xcassets` - app assets.
- `WPswitcherTests` - unit tests.
